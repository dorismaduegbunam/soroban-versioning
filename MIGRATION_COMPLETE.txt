================================================================================
  ENVIRONMENT VARIABLE SETUP
================================================================================

Environment Variable: USE_NEW_WALLET_KIT

Values:
  • false (or omitted)  → Use legacy npm v1.9.5 (default, safe)
  • true               → Use new JSR version

How to Add:
  Option 1: v0 UI (Recommended)
    - Click Vars in left sidebar
    - Add variable: USE_NEW_WALLET_KIT = false
    
  Option 2: Vercel Dashboard
    - Settings → Environment Variables
    - Add: USE_NEW_WALLET_KIT = false
    
  Option 3: Local Development
    - Create/edit dapp/.env.local
    - Add: USE_NEW_WALLET_KIT=false
